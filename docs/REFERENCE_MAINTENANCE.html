Règles d'architecture (vérifiées par les tests)

  • core/, fits/, drt/, circuit/ : aucun import Streamlit. fits/, drt/, circuit/ n'importent jamais core (tests/test_architecture.py).
  • plotting/ reçoit des données ; ui/ n'implémente pas de physique ; la page Visualisation n'importe ni fit ni DRT (tests/test_ui_pages.py).
  • Un __init__.py dans chaque paquet, y compris un nouveau dossier.
  • Les tâches de calcul sont des fonctions de niveau module (picklables) qui renvoient des enregistrements core/results.py, jamais les objets internes du pipeline.
Ne pas supprimer core/app_state.py : launch.bat exige sa présence dans une mise à jour (ligne for %%F in (app.py …)) ; sans lui, plus aucune mise à jour ne s'installe. tests/test_app_state.py vérifie tous les fichiers de cette liste.

Archive .zip (schéma v3)

manifest.json (version de schéma, expérience, assignation, config, SHA-256 de chaque fichier) + data/ (données nettoyées) + results/ (JSON + CSV). Les nombres sont écrits avec repr : l'aller-retour est exact. Toute évolution du format :

  1. incrémenter ARCHIVE_SCHEMA_VERSION (core/version.py) ;
  2. garder la lecture de l'ancienne version (ou refuser avec un message clair) ;
  3. étendre tests/test_archive_v3.py (aller-retour exact, aucun appel aux fits).

Archives v2 (experiment.yaml) : core/legacy_import.py (configuration + fichiers bruts).

Recettes

Ajouter une page

  1. ui/page_xxx.py avec render() ;
  2. l'enregistrer dans app.py (nav.PAGES, url_path unique) ;
  3. un test AppTest dans tests/test_ui_pages.py.

Ajouter un résultat calculé

  1. le calculer dans core/ (fonction pure + test) ;
  2. l'ajouter à core/results.py avec meta/from_meta ;
  3. l'écrire/relire dans exports/archive.py ; l'afficher via core/report_tables.py.

Changer la sélection du pic DRT

core/drt_peak.py::main_peak ; ajuster tests/test_drt_peak.py, dont le test sur moteur réel (Rs + Rct∥C, ±5 %).

Ajouter une option de ligne de base CV

Dans core/cv.py::anodic_peak (option de config cv.baseline à ajouter dans core/config.py::CVSettings) ; documenter et tester sur tests/data/cv_bare_2cycles.txt.
